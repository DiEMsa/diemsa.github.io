## 📌 Project Overview

This project is my personal developer portfolio, designed to provide a professional overview of my software development journey and selected technical work.

The website presents my skills and experience through a modern, responsive interface with dedicated sections for my introduction, skills, projects, services, resume, education, experience, and contact details.

The portfolio is built as a lightweight static website using standard web technologies, making it easy to maintain and deploy with **GitHub Pages**.

## 🚀 Installation Instructions

This is a static website, so no backend server, database, or package installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/DiEMsa/diemsa.github.io.git
```

### 2. Navigate to the project directory

```bash
cd diemsa.github.io
```

### 3. Run locally

Open `index.html` directly in a web browser, or use a local development server such as **VS Code Live Server**.

### 4. Deploy with GitHub Pages

Push your changes to the `main` branch and configure GitHub Pages to deploy from the repository.

The live portfolio is available at:

**https://diemsa.github.io/**
